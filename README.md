# PACEPLAY
npm install && npm run dev (test: npm test · build: npm run build)
Déploiement gratuit : pousser sur GitHub, activer Pages (GitHub Actions « static ») sur le dossier dist, ou Cloudflare Pages (build: npm run build, output: dist). HTTPS requis pour le GPS.
iPhone : Safari → Partager → Sur l'écran d'accueil.
